## 4. Refleksi

### 1. Platform mana yang paling menarik untuk dipelajari? Mengapa?

Menurut saya, platform Mobile merupakan platform yang paling menarik untuk dipelajari karena saat ini smartphone banyak digunakan dalam kehidupan sehari-hari. Aplikasi mobile memudahkan pengguna untuk berkomunikasi, belajar, mencari informasi, dan melakukan berbagai aktivitas lainnya. Saya ingin mempelajari cara membuat aplikasi mobile yang memiliki tampilan menarik, mudah digunakan, dan dapat membantu menyelesaikan kebutuhan pengguna.

### 2. Apa tantangan terbesar saat setup environment?

Tantangan terbesar saat melakukan setup environment adalah menginstal berbagai perangkat lunak dan memastikan semuanya dapat berjalan dengan baik. Git digunakan untuk mengelola versi kode, Node.js dan NPM mendukung pengembangan aplikasi berbasis JavaScript, sedangkan Java JDK digunakan untuk pengembangan aplikasi dengan Java. Selain itu, kesalahan konfigurasi dan masalah autentikasi GitHub dapat menghambat proses pengiriman file ke repository.

### 3. Bagaimana rencana Anda mengatasi tantangan tersebut?

Saya akan mengatasi tantangan tersebut dengan mengikuti petunjuk instalasi dari dokumentasi resmi, memeriksa versi setiap perangkat lunak melalui terminal, dan membaca pesan kesalahan dengan teliti. Jika mengalami masalah, saya akan mencari solusi dari sumber terpercaya dan mencoba memperbaikinya secara bertahap. Saya juga akan berlatih menggunakan Git dan GitHub agar lebih memahami proses commit dan push. Dengan demikian, saya berharap dapat mengembangkan kemampuan pemrograman dan mempersiapkan lingkungan kerja yang baik untuk tugas berikutnya.
