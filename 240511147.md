# Analisis Komparatif Platform Web, Desktop, dan Mobile

## 1. Tabel Perbandingan Platform

| Aspek | Web | Desktop | Mobile |
|---|---|---|---|
| Bahasa utama | HTML, CSS, JavaScript | Java, C#, C++, Python | Kotlin, Java, Swift, Dart |
| Arsitektur | Client-server, berjalan melalui browser | Aplikasi berjalan pada sistem operasi komputer | Aplikasi berjalan pada sistem operasi perangkat mobile |
| Cara distribusi | Melalui URL dan web server | Melalui installer, toko aplikasi, atau paket aplikasi | Melalui Play Store, App Store, atau distribusi APK |
| Keunggulan | Mudah diakses melalui browser, tidak selalu perlu instalasi pengguna | Dapat memanfaatkan sumber daya komputer dan fitur sistem operasi | Praktis, portabel, dan dapat memanfaatkan fitur perangkat seperti kamera dan GPS |
| Keterbatasan | Bergantung pada browser dan dapat bergantung pada koneksi internet | Perlu memperhatikan kompatibilitas sistem operasi dan perangkat | Memiliki keterbatasan ukuran layar, baterai, dan kompatibilitas perangkat |
| Contoh aplikasi | Google Docs, Gmail versi web | Microsoft Word versi desktop, Visual Studio Code | WhatsApp Mobile, Google Maps Mobile |

## 2. Kesimpulan

Platform Web, Desktop, dan Mobile memiliki karakteristik yang berbeda. Web cocok untuk aplikasi yang mudah diakses melalui browser. Desktop cocok untuk aplikasi yang membutuhkan integrasi dengan sistem operasi komputer. Mobile cocok untuk aplikasi yang digunakan secara praktis melalui smartphone. Pemilihan platform perlu disesuaikan dengan kebutuhan pengguna, fitur aplikasi, dan perangkat yang digunakan.
